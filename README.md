## Завдання

### 1. Фігури Лісажу та поліном Чебишева
- Фігури Лісажу `x = cos(ω₁t + φ₁)`, `y = cos(ω₂t + φ₂)` 1-го рангу (ω₁/ω₂ = 1) та 2-го рангу (ω₁/ω₂ = 2).
- Вплив різниці фаз Δφ на вигляд фігури.
- Випадок ω₁/ω₂ ≠ 1: раціональні та ірраціональні відношення частот.
- Графік полінома Чебишева `Tₙ(x) = cos(n·arccos x)`, n = 5 (для порівняння n = 3…7).

### 2. Годограф Михайлова
- Характеристичний поліном варіанта 3: `D(p) = p¹⁰ + 7p⁸ + 11p⁷ + 5p + 1`.
- Побудова годографа `D(iω)`, приріст аргументу, висновок про стійкість.
- Перевірка алгоритму на стійких системах `(p+1)(p+2)(p+3)` та `(p+1)…(p+4)`.
- **Результат:** система нестійка (Δarg = −2·π/2 замість 10·π/2; 6 коренів у правій півплощині).

### 3. Банкомат
- Програма за схемою алгоритму (стани a0…a13): розпізнання картки, перевірка коду, повторний ввід,
  блокування, меню (стан рахунку / зняття готівки / вихід), перевірка наявності коштів.
- Початкова сума рахунку випадкова (гривні та копійки).
- Режими: демонстрація та інтерактивний.

## Як запустити в Google Colab
1. Відкрити https://colab.research.google.com
2. **Файл → Завантажити блокнот** → вибрати потрібний `.ipynb`.
3. **Середовище виконання → Виконати все** (Runtime → Run all).
   Бібліотеки `numpy`, `scipy`, `matplotlib` у Colab вже встановлені.
4. Графіки з'являються під комірками й зберігаються в папку `results/`
   (ліворуч іконка «Файли» → `results`), звідки їх можна завантажити для звіту.
5. **Завдання 3:** остання комірка запитає режим. Введіть у поле під коміркою:
   `1` — демонстрація, `2` — інтерактивний, `3` — обидва, і натисніть Enter.
   В інтерактивному режимі: картка 1 — код 1234, картка 2 — код 4321,
   картка 3 має непідтримуваний тип; `q` вимикає банкомат.

Пояснення до кроків — у текстових комірках над кодом, висновки — внизу кожного блокнота.
