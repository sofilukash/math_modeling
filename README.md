## Завдання
 
### 1. Фігури Лісажу та поліном Чебишева
- Фігури Лісажу `x = cos(ω₁t + φ₁)`, `y = cos(ω₂t + φ₂)` 1-го рангу (ω₁/ω₂ = 1) та 2-го рангу (ω₁/ω₂ = 2).
- Вплив різниці фаз Δφ на вигляд фігури.
- Випадок ω₁/ω₂ ≠ 1: раціональні та ірраціональні відношення частот.
- Графік полінома Чебишева `Tₙ(x) = cos(n·arccos x)`, n = 5 (для порівняння n = 3…7).
### 2. Годограф Михайлова
- Характеристичний поліном варіанта 3: `D(p) = p¹⁰ + 7p⁸ + 11p⁷ + 5p + 1`.
- Побудова годографа `D(iω)`, приріст аргументу, висновок про стійкість.
- Перевірка алгоритму на стійких системах `(p+1)(p+2)(p+3)` та `(p+1)…(p+4)`.
- **Результат:** система нестійка (Δarg = −2·π/2 замість 10·π/2; 6 коренів у правій півплощині).
### 3. Банкомат
- Програма за схемою алгоритму (стани a0…a13): розпізнання картки, перевірка коду, повторний ввід,
  блокування, меню (стан рахунку / зняття готівки / вихід), перевірка наявності коштів.
- Початкова сума рахунку випадкова (гривні та копійки).
- Режими: демонстрація та інтерактивний.

## Мета роботи
Оволодіти засобами пакета `scipy` (`scipy.signal`) для імітаційного моделювання лінійних неперервних систем:

## Завдання
 
### 1. Передатні функції лінійних ланок
- Передатна функція варіанта 3: `G(p) = (p² − 7p + 3) / (11p⁴ + 5p + 1)`.
- zpk-форма (`tf2zpk`): нулі, полюси, коефіцієнт підсилення; висновок про стійкість.
- Для нестійкої системи — стійка замкнена система за схемою Рис. 5 із підбором коефіцієнта `k_u`.
- Модель ланки, її імпульсна характеристика та перехідна функція.
- Відгук на гармонічний вхід: коефіцієнт посилення та зсув фази.
- Годограф Найквіста, АЧХ та ФЧХ; резонанси, явища «запирання», зв'язок із стійкістю та між АЧХ і ФЧХ.
- Диференціальне рівняння, що відповідає передатній функції; перевірка збігу відображення «вхід–вихід».
- **Результат:** `G(p)` нестійка (полюси 0,44 ± 0,67i); скалярним `k_u` стабілізувати неможливо
  (нульовий коефіцієнт при s³), тому використано зворотний зв'язок за станом `u = k_u·r − Kx`.
### 2. Задача реалізації
- Моделі в просторі станів у канонічних формах керованості (КФК) та спостережуваності (КФС): матриці `A`, `B`, `C`.
- Перевірка тотожності матричних передатних функцій `C(pI − A)⁻¹B` початковій `G(p)`.
- Порівняння відображення «вхід–вихід» для КФК, КФС і початкової ланки.
